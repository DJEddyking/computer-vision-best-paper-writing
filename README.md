# Computer Vision Best Paper Writing

面向 **CVPR、ICCV 和 ECCV** 的计算机视觉论文写作技能。它参考最佳论文的论证方式，帮助作者讲清楚视觉问题、方法为什么有效，以及哪些实验和图表支撑论文的主张。

## 它能做什么

- **起草**：从研究笔记、实验结果或 LaTeX 项目出发，规划和撰写摘要、引言、方法与实验，并组织配图。
- **修改**：润色现有草稿，保留技术含义、实验数字和引用键，并解释关键改动。
- **审阅**：检查主张是否有证据支撑、视觉对比是否公平，以及图表能否讲清方法和结果。证据缺失时用 `[TODO]` 标记。

## 针对计算机视觉做了哪些调整

1. **溯源写作参考。** [引言指南](references/introduction.md)用 Mask2Former、Swin Transformer 和 DETR 的例子说明不同的论证写法，并给出论文链接和对应的章节或图号。使用技能时，可以要求把采用了哪些写作参考、借鉴了哪种论证方式记录在修改说明中，方便回到原文核对。
2. **使用自建参考资料库。** 可以按子领域或目标会议整理自己的论文、读书笔记和 BibTeX 条目，并在任务中提供可访问的文件或目录。技能可从这些材料里找与当前任务匹配的写作范例，例如优先用目标会议中同一研究方向的论文来参考引言结构。
3. **加入作者自定义写作准则。** 可以在任务里直接写下准则，也可以指定一份团队风格指南。例如，要求正文不使用分号，把包含多层从句的句子拆开，并统一关键术语。起草和审阅时都可以按同一份准则执行。

## 快速开始

从 [SKILL.md](SKILL.md) 了解工作流。提供目标会议及年份、需要处理的章节和现有材料，并按需指定参考资料库和作者准则。

> 用 Computer Vision Best Paper Writing 技能修改这份 CVPR 引言。优先参考我提供的论文库，并在修改说明里列出借鉴的论文及对应章节。正文不要使用分号，把多层从句拆成短句。保留实验数字和引用键，缺少证据的地方用 `[TODO]` 标记。

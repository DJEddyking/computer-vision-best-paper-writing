## 写作工作流

| 阶段 | 技能如何协助 |
| :--- | :--- |
| **起草** | 从研究笔记、实验结果或 LaTeX 项目出发，规划摘要、引言、方法、实验和配图。 |
| **修改** | 润色现有草稿，保留技术含义、实验数字和引用键，并解释关键改动。 |
| **审阅** | 检查主张能否对照证据、视觉对比是否公平、图表能否讲清方法和结果。用 `[TODO]` 标记缺失的证据。 |

## CV 写作特色

### 溯源写作参考

[引言指南](references/introduction.md)用 Mask2Former、Swin Transformer 和 DETR 展示不同的论证写法，并标出论文链接及对应章节或图号。可以在任务中要求技能列出参考的论文和段落，以及分别借鉴了哪种论证方式。

### 使用自建参考资料库

按子领域或目标会议整理自己的论文、读书笔记和 BibTeX 条目，再提供可访问的文件或目录。技能可从这些材料里寻找适合当前任务的范例，例如用目标会议中同一方向的论文来参考引言结构。

### 加入作者自定义写作准则

在任务里直接写下准则，或指定一份团队风格指南。起草、修改和审阅时都可以应用同一套要求，例如不用分号、拆分多层从句、统一关键术语。

## 快速开始

在 [SKILL.md](SKILL.md) 查看完整工作流。提交任务时，提供目标会议及年份、待处理的章节和现有材料，并按需指定参考资料库和作者准则。
